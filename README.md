## 🚀 Projetos em destaque

### 🧪 [mark-app-test](https://github.com/reuelsilva/mark-app-test)
Testes E2E de um gerenciador de tarefas (API REST + interface web), com Playwright e TypeScript.
- Page Object Model e limpeza de dados via API antes de cada cenário
- Cenários de criação, duplicidade, campo obrigatório, conclusão e remoção de tarefas
- Coleção Postman para a API e workflow no GitHub Actions

### 🛒 [saucedemo-app-test](https://github.com/reuelsilva/saucedemo-app-test)
Automação E2E do fluxo de compra do SauceDemo, de login a finalização do pedido.
- POM com `PageManager`, fixtures customizadas e dados dinâmicos com Faker
- Cobertura de login, inventário, carrinho e checkout (incluindo cálculo de subtotal, taxa e total)
- Execução em Chromium, Firefox e WebKit
- Documentação de histórias, cenários e critérios de aceite na pasta [`docs/`](https://github.com/reuelsilva/saucedemo-app-test/tree/main/docs)
